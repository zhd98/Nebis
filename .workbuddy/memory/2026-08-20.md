## 极简 Markdown 编辑器（纯 Win32 + Scintilla）
用户要做类 Notepad 的极简 Markdown 编辑器：纯 Win32、无 WebView、无预览，行内语法淡化（`#` 灰色隐藏，标题放大彩色）。

- 选定方案：Scintilla + C++（MinGW 静态链接）。运行时需 `Scintilla.dll` + `Lexilla.dll`（SciTE 5.6.6 发布包 `wscite566.zip`），不再提供单体 `SciLexer.dll`。
- Markdown 词法器通过 `CreateLexer("markdown")` → `SCI_SETILEXER(4033)` 挂载。
- 关键样式：`SCE_MARKDOWN_LINE_BEGIN=1`（符号灰化）、`SCE_MARKDOWN_HEADER1..6=6..11`（标题放大彩色）。
- 头文件已 vendored 到 `src/scintilla/`（取自 5.6.6 源码包）。
- 工程：`CMakeLists.txt`（MinGW，静态链接运行时）、`.github/workflows/build.yml`（msys2 + 下载 DLL + 编译，产出 `mdpad-win64` artifact）、`README.md`、`.gitignore`。
- 用户要求：不本地编译，上传 GitHub 后由 Actions 编译 exe。
- 已写文件：src/main.cpp（框架/菜单/标签）、src/editor.cpp（Scintilla 封装/样式/UTF-8 读写）、src/findreplace.cpp（查找替换）。
- 未本地编译（遵守用户要求），仅对照官方头文件逐项核对常量与调用约定。

## CI 下载超时修复
- 症状：GitHub Windows runner 连不上 `scintilla.org`，`Invoke-WebRequest` 下载 `wscite566.zip` 超时退出码 1。
- 修复：把 `Scintilla.dll` + `Lexilla.dll`（取自本地已下载的 `wscite566.zip`）vendored 到仓库 `runtime/`，`build.yml` 改为直接 `cp runtime/*.dll artifact/`，去掉所有联网下载步骤。
- 关键坑：原 `.gitignore` 中的 `Scintilla.dll`/`Lexilla.dll` 无前导斜杠，会忽略**任意层级**的同名文件，导致 `runtime/` 下的 DLL 也被忽略、CI 拿不到。已改为 `/Scintilla.dll`、`/Lexilla.dll`（只匹配仓库根），保证 `runtime/` 的 DLL 被 git 跟踪。
- 用户自己 git（commit/push），agent 不参与 git。
- 交付状态：CI 修复完成，待用户手动 git 触发 Actions。
